配置和业务数据仍由宿主管理，安装包不包含后端实现或运行配置。

支持 Default、Classic 两套原生入口，Root 可上传安装。保留来源 QuantumNous/new-api 与 MaoLaoNewAPI，许可证见仓库 LICENSE。
